# ww-discord-auth

Tiny login server for "Sign in with Discord". Deploy on Render (free). See render.yaml.

Env vars (Render > Environment):
- DISCORD_CLIENT_SECRET - from discord.com/developers > your app > OAuth2 (the Application ID is read from Firebase: users/{DISCORD_APP_OWNER_KEY}/discord_signin_id, saved in Settings)
- FIREBASE_SERVICE_ACCOUNT - the whole service-account JSON for project entertainment-71888
  (Firebase console > Project settings > Service accounts > Generate new private key)
- STATE_SECRET - auto-generated by render.yaml
- PUBLIC_URL / ALLOWED_ORIGINS - preset in render.yaml

Discord app: OAuth2 > Redirects must contain  https://ww-discord-auth.onrender.com/callback
Firebase console: Authentication > Settings > Authorized domains is NOT needed (custom token, no popup).
